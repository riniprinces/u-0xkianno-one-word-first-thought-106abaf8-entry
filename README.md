A one-word make.fun bounty entry. The program writes a single word — **vellichor**, the strange smell of old bookshops — to `/output/entry.txt`, the first word that came to mind, with no explanation and no second draft.

## Run it

```sh
node main.ts
```

This writes `vellichor` to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that variable is set). The word is embedded in `main.ts` itself; the program is fully deterministic and uses no network.
